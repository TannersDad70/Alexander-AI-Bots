How to install (sideload)

  1. Tap the Download for Android (APK) button above to get the APK file.
  2. Open the downloaded file — from the download notification or your Downloads folder.
  3. If Android asks, allow "Install unknown apps" for your browser (Settings → Apps → Special app access → Install unknown apps).
  4. Tap Install, then Open.
  5. Enter your OpenRouter API key in Settings — your key stays on your device.

No download? Add to Home Screen (PWA)

You can install the web app as a home-screen icon instead — no APK needed:

  1. Android (Chrome): open the app, tap the ⋮ menu, then "Add to Home screen" → Add.
  2. iPhone (Safari): open the app, tap Share, then "Add to Home Screen" → Add.
